
CAMPUS BREW
Professional Cafe Website | 2026

PROJECT OVERVIEW
Campus Brew is a modern, responsive cafe website
developed as part of the AI Foundations & Ethical AI
course at UPES.

TECHNOLOGIES USED
- HTML5
- CSS3
- JavaScript

WEBSITE PAGES
1. Home - Cafe introduction and highlights
2. Menu - Food items, descriptions and prices
3. About - Story, mission, vision and values
4. Contact - Interactive contact form
5. Order - Shopping cart and checkout interface

KEY FEATURES
- Responsive website design
- Mobile-friendly navigation
- Premium orange and cream theme
- Six food and beverage items
- Multi-item shopping cart
- Quantity increase and decrease controls
- Automatic price calculation
- Remove items from cart
- UPI, Card and Cash payment selection
- Order summary
- Contact form validation

HOW TO RUN
1. Open the project folder.
2. Open index.html in a modern web browser.
3. Navigate between pages using the menu.
4. Explore the shopping cart and checkout.

PROJECT SCOPE
This is a frontend-only academic website.
Shopping cart calculations and payment method
selection work within the browser.

Orders are not transmitted to a cafe.
No real payments are processed.
Contact messages are not sent to a server.

AI COLLABORATION
AI assistance was used during website development,
code improvement, debugging and testing.

AI-generated suggestions were reviewed and tested.
The collaboration log and error analysis document
the development and evaluation process.
